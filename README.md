# Projecto-FullStack-CodoACodo-FROTEND

## Descripcion

### Este proyecto es un sitio web de una Galeria de NFTs, donde los usuarios pueden navegar buscando nfts, registrarse, iniciar sesion, agregar nfts a su lista de favoritos

### con inicio de sesion, registro de usuario y la lista de favoritos todo guardado en base de datos MYSQL conectada atra vez de una api hecha en JAVA.
